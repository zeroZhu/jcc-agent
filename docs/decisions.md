# 未决问题、答案选项与默认决定

| 问题 | 可选方案 | 当前采用 | 状态 / 理由 |
|---|---|---|---|
| 画之灵是原版还是返场及具体补丁？ | 原版特定补丁 / 返场 / 用户自定义 | 配置记录来源和版本，未核实数据标记为参考 | 待根据素材与规则资料核实，不假定 TFT 和金铲铲完全相同 |
| 运行设备是什么？ | Windows 模拟器 / Android 真机 | Windows 固定窗口与分辨率的适配层 | 工程默认，待用户实际设备校准 |
| 星级只有图标时怎么办？ | 读文字替代信息 / 视觉图标识别 / 未知范围 | 未知范围；保持纯 OCR | 不引入图像分类，不能将未知默认成一星 |
| 一回合扫不完对手怎么办？ | 强制扫完 / 分批继续 / 只看同行 | 分批继续，支持重点玩家 | 允许低时效，自己操作优先 |
| 低置信商店怎么处理？ | 猜测 / 重试 / 跳过 | 重试，超时暂停本轮刷新 | 避免跳过目标牌和错误购买 |
| 是否自动卖掉不认识或星级不确定的棋子？ | 自动清理 / 保留并暂停 | 保留并暂停 | 卖牌不可从录像还原，必须有可信持牌状态 |
| 选择奇遇和强化的规则？ | 完全自动 / 可配置偏好 / 人工 | 提供可配置文本偏好；无可靠匹配暂停等待 | 不假装具备未验证的全量选项知识 |
| 开发时是否直接操作游戏？ | 自动运行 / 仅观察 / 录像和记录动作 | 录像验证与动作记录优先；实时执行显式启用 | 用户未提供已校准游戏窗口，不能盲点桌面 |
| 录屏时间标签是否用于在线识别？ | 用时间直接判断 / 仅用画面文字 | 时间标签仅作为评估真值 | 防止用答案冒充阶段识别 |
| D 牌 1–2 秒是否硬限制？ | 硬定时 / 操作确认后的目标间隔 | 目标间隔，购买和重试允许延长 | 上一动作未确认前绝不继续刷新 |
| 初始己方持牌如何获取？ | 全自动识别 / 人工核对基线 / 只给建议 | 当前核对37格后用确认交易追踪；无基线只观察 | 星级与空位没有稳定文字，不能声称已自动初始化 |
| 玩家名字随角色移动怎么办？ | 猜自己 / 校准文字映射 / 审阅会话上下文 | 名称映射优先；可显式启用当前己方上下文 | 日志保留人工来源与原时刻；导航前失效，外部键鼠/失焦停止 |
| 商店隐藏时如何打开？ | 将OCR空白当隐藏 / 找关闭文字证据 / 启动前打开 | 启动前打开商店 | 当前只证明可见True，缺少关闭False证据；open_shop控制动作不等于默认感知已支持自主展开 |
| 没有阶段文字时如何处理？ | 猜准备期 / 粗分正常对局 / 等待 | 有可信回合、倒计时及商店时标gameplay；否则unknown | gameplay允许经济操作及返家，不授权棋盘扫描 |
| 售价与基础费用不同？ | 按基础费 / 读现价 | 逐格读取实际售价 | 一元店录屏验证19张售价正确，基础费只用于牌库分层 |
| 免费刷新及特殊合成是否接入？ | 全部猜规则 / 每机制建契约 / 忽略差异 | 每机制单独适配；当前未支持则暂停 | 当前刷新按2金币确认，免费刷新无法确认时停止，不继续点击 |
| 不同OpenCV发行包共存？ | 都安装 / 只保留Paddle所需contrib | 只保留opencv-contrib-python 4.10.0.84 | 环境检查通过，已重新跑12帧×2实测 |
